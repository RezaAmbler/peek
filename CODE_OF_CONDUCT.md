# Code of Conduct

## Our Pledge

The PEEK project is committed to providing a welcoming and respectful environment for everyone who contributes, opens an issue, or participates in our community spaces. We expect all participants to behave professionally and treat each other with kindness and respect.

## Our Standard

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. The full text is available at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Translations: https://www.contributor-covenant.org/translations/

By contributing to PEEK or participating in PEEK community spaces (issues, pull requests, discussions, security reports), you agree to abide by the terms of the Contributor Covenant 2.1.

## Scope

This Code of Conduct applies within all project spaces — including the GitHub repository, issue tracker, pull requests, discussions, and any communication channels operated on behalf of PEEK — and also applies when an individual is officially representing the project in public spaces.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it privately to:

**reza.ambler@gmail.com**

Reports will be reviewed and investigated promptly and fairly. All complaints will be handled with discretion; the privacy and safety of the reporter is a priority.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the Code of Conduct. Maintainers may take any action they deem appropriate in response to violations, ranging from a private warning to a permanent ban from project spaces. The [Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) section of the Contributor Covenant 2.1 describes the framework used for these decisions.
